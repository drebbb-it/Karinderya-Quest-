# KARINDERYA QUEST GAME DEVELOPMENT (Unity Engine)
### About: This is a game development school project about managing or operating a "Karinderya" or an Eatery using Unity Engine.
#### Technology Used:
##### C#
##### Unity Engine
#### Game:
### - Scene 1: Platform Game(Ingredients), collecting ingredients so the player can use the ingredients to cook.
### - Scene 2: Drag and Drop(Cooking), collected ingredients can be put into a cooking pot to cook dishes. We have 4 dishes (Adobo, Menudo, Afritada, and Giniling).
### - Scene 3: Drag and Drop(Serving), using the cooked dishes in Scene 2, players can serve the customers based on their desire food choices.
